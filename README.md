# fancytextlib
Simple Python library to allow for text styling.

## What makes this library better
- **No additional libraries:** all libraries are pre-installed with Python.
- **Cross-platform support:** all Unix-based systems and Windows 10 (version 1909) and up supports ANSI escape codes, which this project is built on.
- **Easy to implement:** You just insert the commands into f-strings (or use concatenation) to add colour and styling.
